**Instructions to run**
1. Clone the repository and store it in your desired folder
2. Install Java JDK 21 on your system
3. Open the project in an IDE (IntelliJ IDEA or VS Code)
4. Navigate to: src/main/java/com/example/VrCollabServer/VrCollabServerApplication.java
5. Run the VrCollabServerApplication.java file
6. The application will start on http://localhost:8080
